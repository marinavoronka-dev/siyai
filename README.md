# Сияй!

## Запуск на компьютере

Нужен Python 3. В папке проекта выполните:

```sh
python3 -m http.server 3000 --directory dist
```

Откройте http://localhost:3000. Установка на телефон и офлайн-режим работают через HTTPS или localhost. Для хостинга используйте содержимое папки `dist`.

Автор проекта — МАРИНА ВОРОНЦОВА.

Статическое приложение: `dist/index.html`, изображения и собранные стили в `dist/assets/`.

## Сбор отзывов и заявок

Формы отправляются из браузера через FormSubmit на `art@marina-vorontsova.ru`.
Endpoint: `https://formsubmit.co/ajax/art@marina-vorontsova.ru`.

Для первого подключения автору нужно:

1. Открыть сайт и отправить тестовый отзыв через новую кнопку отправки.
2. Проверить почту `art@marina-vorontsova.ru`, включая спам, и подтвердить адрес по письму FormSubmit.
3. Отправить тестовый отзыв снова и убедиться, что письмо пришло. Первое сообщение может не доставиться до активации.
4. Проверить отдельную заявку, указав адрес для ответа.

Пароли в приложении не хранятся. Контакт для ответа нужен только для заявок; отзыв не требует имени или email участницы. Текст перед отправкой виден пользователю. FormSubmit является внешним обработчиком формы, собственная база отзывов не создавалась; записи поступают в почту автора.

Формы сообщают о принятии только после ответа сервиса. При ошибке, отсутствии сети или ожидании активации текст остаётся в окне. Для отзывов доступен запасной mailto; для заявок — ручная связь в Telegram. Не сообщать о гарантированной доставке на основе одного HTTP-ответа.

Проверки нового потока выполнены со смоделированными ответами сервиса. Живая доставка и активация адреса пока не подтверждены: доступ к домену FormSubmit из среды разработки заблокирован сетевой политикой. Проверку выполняет автор в своём браузере и почте.

## Ежедневные подсказки

30 напутствий меняются по календарной дате в часовом поясе браузера. Фраза стабильна внутри одного дня. Открытая страница проверяет обновление раз в минуту и при возвращении во вкладку.

## Мобильная версия

Интерфейс адаптирован для узких экранов до 640px: нижнее меню, переключатель утреннего/вечернего чек-листа, крупные зоны нажатия, нижние панели диалогов и поля ввода 16px. Масштабирование браузера разрешено; предусмотрены безопасные отступы у вырезов экрана.

`dist/manifest.webmanifest` задаёт режим отдельного приложения и иконку Мии. На Android используется системная установка, когда браузер её предлагает; для остальных случаев есть инструкции добавления ярлыка. На iPhone используется Safari → Поделиться → На экран Домой.

`dist/sw.js` сохраняет основную страницу и открытые статические материалы для офлайн-чтения. Отправка форм, внешние сервисы и маршруты авторизации не кэшируются. Ошибка заполнения кэша не препятствует обычной онлайн-загрузке. Данные чек-листов и копилки остаются браузерными; их перенос в установленный режим зависит от браузера, автоматическая синхронизация не реализована.

Логика меню, установки, форм и офлайн-кэширования проверена программно. Визуальная проверка на физических Android/iPhone пока не проводилась.
