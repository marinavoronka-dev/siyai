# Сияй! — бьюти-подружка Мия

Привычки заботы о себе, утренние и вечерние чек-листы, календарь, подсказки и достижения.
Автор — Марина Воронцова.

Репозиторий основан на восстановленной версии от 12 октября 2026 года. Последующая серверная версия сохранена в ветке `backup/before-restore-2026-10-30-f2f7162`.

## Открыть

- [Сайт на GitHub Pages](https://marinavoronka-dev.github.io/siyai/) — доступен после успешной публикации workflow GitHub Pages.
- [Скачать Android APK 1.1](dist/download/Siyai-Mia.apk) — Android 6.0+, нужен интернет.
- [Исходный сайт Sites](https://siyai-mia-beauty.sappyoasis1.chatgpt.site/) — отдельное размещение, обновление GitHub его не меняет.

## Запуск на компьютере

Нужен Node.js 22 или новее. Зависимости устанавливать не требуется.
```sh
npm run dev
```
Откройте http://localhost:3000. Файлы сайта находятся в `dist/`; сборки веб-интерфейса нет, редактируется готовый HTML/CSS/JavaScript.

## Проверки

```sh
npm run check
npm test
```
Проверяются синтаксис JavaScript, манифест, локальные ресурсы и маршрутизация service worker в корне и подпапке. Это не заменяет проверку интерфейса и доставки форм.

## Публикация сайта

Settings → Pages → Source: **GitHub Actions** (однократно).
После изменения `dist/` и отправки в `main` workflow `GitHub Pages` проверяет и публикует сайт. Также доступен ручной запуск через Actions.
Манифест и офлайн-кэш поддерживают `/siyai/`. При переименовании репозитория обновите адрес HOME в `android/src/ru/siyai/mia/MainActivity.java`.

## Android

[Как собрать APK и настроить подпись](android/README.md).
Workflow `Android APK` автоматически собирает тестовый APK при изменении `android/`.
Для выпуска с постоянной подписью запускайте вручную `release` после добавления секретов. Ключи подписи не публикуются в репозитории.

## Данные и формы

Отметки и копилка сохраняются локально: между устройствами, APK и браузером автоматической синхронизации нет. Очистка данных или удаление приложения удаляет прогресс.
Офлайн доступны ранее открытые материалы; для первого запуска, форм и внешних сервисов нужен интернет.

В восстановленной версии формы используют внешний FormSubmit. Доставка писем зависит от активации адреса автором и доступности сервиса; живая доставка не подтверждена. Серверного кабинета автора в этой версии нет.
Не добавляйте в отзывы фото детей, адреса, школу, телефоны и другие лишние личные данные.
