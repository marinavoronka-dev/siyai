# Сияй! 1.1 для Android

[Скачать APK 1.1](https://github.com/marinavoronka-dev/siyai/raw/refs/heads/downloads/android-v1.0/downloads/siyai-1.1.apk)

Android 6.0+, около 3.3 МБ. Устанавливайте поверх 1.0 без удаления: подпись и идентификатор приложения сохранены, versionCode увеличен до 2.

Версия 1.1 открывает именно https://siyai-mia-beauty.sappyoasis1.chatgpt.site/ внутри приложения, включая серверную отправку отзывов на этом сайте. Это онлайн-оболочка: для загрузки нужен доступ к сайту и интернет. Предыдущий APK 1.0 содержал другую, восстановленную версию; он оставлен в истории, но больше не рекомендуется. Полный офлайн-режим для 1.1 не заявляется.

Проверьте интерфейс, календарь, отзывы, клавиатуру и кнопку назад на телефоне. На физическом устройстве 1.1 ещё не проверен. Подпись APK проверена и совпадает с 1.0.

Прогресс браузера не переносится автоматически в Android WebView. Данные локальной версии 1.0 не отображаются на новом домене; приложение при обновлении их не удаляет.

Сайт и main не изменены; ключ подписи, пароли и исходники Android-оболочки здесь не публикуются.
