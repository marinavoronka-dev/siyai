# Сияй! 1.0 для Android

[Скачать APK](https://github.com/marinavoronka-dev/siyai/raw/refs/heads/downloads/android-v1.0/downloads/siyai-1.0.apk)

Android 6.0+, около 36 МБ. Подпись APK проверена. На физическом телефоне ещё не проверен.

Откройте APK на телефоне, при запросе разрешите установку из браузера. Проверьте первый запуск, календарь, чек-листы и сохранение отметок после закрытия. Основные материалы должны открываться без интернета; отправка отзывов требует работающего сборщика и интернета. Доставка отзывов в Telegram пока не подтверждена.

Ключ подписи и его пароль здесь не публикуются.
